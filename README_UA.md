# 🤖 Telegram AI Assistant with SQLite Memory & Gemini API

Професійний асистент у Telegram, побудований на асинхронному фреймворку `aiogram 3` із інтеграцією штучного інтелекту Google Gemini та локальною баз даних SQLite для збереження нотаток і контексту розмови.

---

## ⚙️ Основні можливості

- 🧠 **Персоналізований діалог (Gemini AI):** Збереження історії розмови у базі даних SQLite дозволяє боту пам'ятати попередні повідомлення кожного користувача окремо навіть після перезапуску сервера.
- 📋 **Менеджер нотаток:** Повноцінне CRUD-управління особистими нотатками (`/note`, `/notes`, `/del`) із прив'язкою за `user_id`.
- ⚡ **Ніколи не блокує потік (Non-blocking I/O):** Виклики API Gemini обробляються через `asyncio.to_thread`, що забезпечує високу швидкість реагування бота для багатьох користувачів одночасно.
- 🔒 **Безпека середовища:** Конфігурація та секретні ключі винесені в `.env` середовище через `python-dotenv`.
- 🧹 **Очищення контексту:** Команда `/clear` для швидкого скидання історії листування в БД та оперативній пам'яті.

---

## 🛠 Технологічний стек

* **Мова:** Python 3.10+
* **Telegram Bot API Framework:** [aiogram 3.x](https://docs.aiogram.dev/)
* **AI Model:** [google-genai](https://pypi.org/project/google-genai/) (Gemini 2.5 / 1.5 Flash)
* **Database:** SQLite3
* **Environment Security:** `python-dotenv`
